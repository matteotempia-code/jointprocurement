# Product documentation

Questa directory contiene la documentazione canonica di prodotto di Sorgence.

## Feature Register

`FEATURE_REGISTER.md` è la **fonte di verità** per l'elenco delle feature, la milestone di riferimento e la percentuale di realizzazione.

Regole:

- ogni milestone deve aggiornare il registro quando modifica, completa, certifica o introduce una feature;
- ogni feature sotto il 100% deve indicare esplicitamente perché non è completa;
- 100% significa implementata, persistente, testata e certificata sul cloud DEV nel perimetro definito;
- il solo fatto che il codice esista non è sufficiente per dichiarare una feature completa;
- nuove idee di prodotto approvate devono essere aggiunte al registro anche se sono ancora allo 0%;
- il registro va aggiornato nello stesso commit/PR della milestone o in un commit immediatamente collegato.

La roadmap e le percentuali presenti nel registro devono essere trattate come stato canonico del prodotto fino al successivo aggiornamento verificato.
